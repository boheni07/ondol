## 1. 스크린 유형 정의

| 코드 | 유형 | 설명 | 대표 화면 |
|------|------|------|---------|
| **ST-01** | Hub / Dashboard | 복수 섹션 요약 카드 + 빠른 진입점 | 보호자 대시보드, 치료사 홈 |
| **ST-02** | List | 아이템 목록 (무한 스크롤 / 페이지네이션) | 기록 목록, 이해관계자 목록 |
| **ST-03** | Detail | 단일 아이템 읽기 전용 상세 | 기록 상세, 인수인계 상세 |
| **ST-04** | Form — Single | 단일 페이지 입력 폼 | 프로필 수정, 간단 기록 입력 |
| **ST-05** | Form — Multi-step | 단계 분할 위자드 폼 | IEP 작성, 당사자 등록, 일지 작성 |
| **ST-06** | Timeline | 시간순 피드 · 생애주기 구간 표시 | 생애주기 타임라인 |
| **ST-07** | Matrix / Table | 행·열 표 구조 + 인라인 필터 | 권한 매트릭스, 접근 로그 |
| **ST-08** | Icon Selector | 대형 이미지 아이콘 선택 (당사자 전용 접근성 UI) | 자기표현 4단계 |
| **ST-09** | Auth / Onboarding | 인증·역할 선택·최초 설정 | 로그인, 회원가입, 접근성 설정 |
| **ST-10** | Modal / Bottom Sheet | 오버레이 확인·간단 입력 | 삭제 확인, 날짜 선택, 필터 |
| **ST-11** | Settings | 설정 항목 목록 + 토글/셀렉트 | 알림 설정, 접근성 설정 |

## 2. 내비게이션 패턴

### 2-1. 반응형 웹

```
┌──────────────────────────────────────────────┐
│ GLOBAL HEADER  [Logo] [검색] [🔔] [프로필]      │  ← 항상 표시
├──────────┬───────────────────────────────────┤
│          │  브레드크럼 (Depth 3+)               │
│ SIDEBAR  ├───────────────────────────────────┤
│ (240px)  │  SUB-TAB BAR  (Depth 2 진입 시)    │
│          ├──────────────────┬────────────────┤
│ D1 메뉴  │  LIST PANEL     │  DETAIL PANEL  │  ← 768px+ Split View
│ 아이콘   │  (D3)           │  (D4)          │
│ + 레이블 │                 │                │
│          │  (PC: 40%)      │  (PC: 60%)     │
└──────────┴──────────────────┴────────────────┘
```

| 요소 | 사양 | 조건 |
|------|------|------|
| **Sidebar** | 고정 좌측, 접힘(240px ↔ 64px) | 항상 |
| **Global Header** | 높이 64px, 알림·프로필 | 인증 후 전체 |
| **Breadcrumb** | Depth 3 이상 | 자동 생성 |
| **Sub-tab Bar** | 분야/카테고리 수평 탭 | D2 화면 |
| **Split Pane** | List(40%) + Detail(60%) | 1024px+ |
| **Full-width** | 단일 컬럼 컨텐츠 | 768px 미만 |
| **Step Indicator** | 상단 수평 진행 바 | Multi-step form |
| **Sticky Footer** | 저장/다음 CTA 버튼 | Form 화면 |

**Depth별 레이아웃:**

| Depth | 웹 레이아웃 | 비고 |
|-------|-----------|------|
| D1 | Sidebar + Full Content | Hub·Timeline |
| D2 | Sidebar + Sub-tab + Content | 목록/필터 |
| D3 | Sidebar + List + Detail (Split) | 1024px+만 Split |
| D4 | Sidebar + Form (Centered, max-w 720px) | 입력 화면 |
| D5 | Sidebar + Form Step N/N | 하위 상세 |

### 2-2. 모바일 앱

```
┌────────────────────────────┐
│  STATUS BAR                │
├────────────────────────────┤
│  NAV BAR  ← 타이틀 [액션]   │  ← D2+ 스택 화면
├────────────────────────────┤
│                            │
│        CONTENT             │
│        (Stack Screen)      │
│                            │
├────────────────────────────┤
│  BOTTOM TAB BAR            │  ← D1 (전체화면 플로우 시 숨김)
│  [탭1] [탭2] [탭3] [탭4]   │
└────────────────────────────┘
```

| 요소 | 사양 | 조건 |
|------|------|------|
| **Bottom Tab Bar** | 역할별 3~5탭, 아이콘+레이블 | D1, 항상 (플로우 중 숨김) |
| **Navigation Bar** | 타이틀 + 뒤로가기 + 우측 액션 | D2+ 화면 |
| **Bottom Sheet** | 반화면(48%) 또는 전체(92%) | 필터, 빠른 폼 |
| **Full-screen Flow** | 탭바 숨김, 완료 시 Pop | 위자드, 온보딩 |
| **FAB** | 우하단 고정 (+기록 작성) | List 화면 |
| **Pull to Refresh** | 아래로 당기기 새로고침 | List·Timeline |
| **Swipe Actions** | 좌스와이프: 삭제/보관 | List 아이템 |

**Depth별 모바일 전환:**

| Depth | 전환 방식 | 제스처 |
|-------|---------|------|
| D1 → D2 | Tab Switch | 탭 아이콘 터치 |
| D2 → D3 | Push (우측으로) | 뒤로 스와이프 |
| D3 → D4 | Push 또는 Full-screen Modal | — |
| D4 → D5 | Push | — |
| 플로우 Step | 위로 슬라이드 (진행 방향) | — |

## 4. 반응형 웹 IA

### 4-1. 보호자 — 사이드바 메뉴 구조

```
SIDEBAR
├── 🏠 대시보드                     [G-01] ST-01
├── 👤 당사자 선택 (Dropdown)
│   ├── [당사자명1] ←────────────── 선택 후 맥락 고정
│   └── + 새 당사자 등록            [G-03] ST-05
│
├── 📅 타임라인                     [G-10] ST-06
│   ├── 전체 보기 (기본)
│   ├── 분야 필터 ──────────────── [G-11] ST-10 Bottom Sheet
│   └── 이정표만 보기
│
├── 📝 기록 관리                    [G-20] ST-02
│   ├── 전체 기록
│   ├── A. 의료                     [G-21] ST-02
│   ├── B. 교육
│   ├── C. 복지서비스
│   ├── D. 일상/돌봄
│   ├── E. 전환/자립
│   └── F. 법적/행정
│
├── 🔑 권한 관리                    [G-30] ST-07
│   ├── 이해관계자 매트릭스
│   └── + 권한 부여                 [G-32] ST-05(4step)
│
├── 📊 접근 로그                    [G-40] ST-07
│
├── 🔔 알림                        [G-50] ST-02
│
└── ⚙️ 설정                        [G-60] ST-11
    ├── 내 프로필
    ├── 당사자 정보 관리
    └── 알림 설정
```

**기록 관리 D2 → D4 흐름 (웹):**

```
기록 목록 [G-21]     →  기록 상세 [G-22]    →  수정 [G-24]
ST-02                    ST-03                   ST-05
[List Panel]             [Detail Panel]          [Form, max-w 720]
  검색·필터 바              본문 + 첨부파일           Step 진행 바
  정렬 (최신/날짜)           이전/다음 기록 이동        취소 | 저장
  + 새 기록 버튼             댓글/메모 (향후)          (sticky footer)
```

### 4-2. 당사자 — 사이드바 메뉴 구조

```

├── 🌟 오늘 기록                    [P-01] ST-01
│   └── 자기표현 입력               [P-02] ST-05+ST-08
│
├── 📖 내 기록 보기                 [P-10] ST-02
│   └── (기록 상세)                 [P-11] ST-03
│
```

## 6. 주요 플로우 Step 정의

### Flow-1. 당사자 자기표현 기록 (P-02)

**트리거:** 홈 → "오늘 기록하기" 버튼  
**타입:** Full-screen Flow, ST-08 (Icon Selector) × 4  
**총 스텝:** 4 + 완료 1 = **5 화면**

| Step | 화면명 | 선택 항목 | 선택 유형 |
|------|--------|---------|---------|
| 1/4 | 기분이 어때요? | 😊좋아요 / 😐보통 / 😢슬퍼요 / 😡화났어요 / 😰불안해요 | 단일 선택 |
| 2/4 | 밥 먹었어요? | 🍚잘먹음 / 😐조금먹음 / 😞별로 / ❌못먹음 + 📷사진(선택) | 단일 선택 + 선택 액션 |
| 3/4 | 오늘 뭘 했어요? | 🏃운동 / 📚공부 / 🎨만들기 / 👫친구 / 🏥병원 / 🛒쇼핑 / 🏠집 / 🎮게임 / 💆치료 / 💼일 | **복수 선택** |
| 4/4 | 몸은 어때요? + 메모 | 💪건강 / 🤧감기 / 😴피곤 / 🤕아파 + 📝메모/🎙음성(선택) | 단일 선택 + 선택 액션 |
| 완료 | ✨ 저장 애니메이션 | — | 자동 Pop (2초 후) |

**모바일 UI 규칙:**
- 각 스텝: 1화면 = 1질문, 아이콘 크기 최소 80×80px
- Progress Bar: 상단 4칸 점 표시 (●●○○)
- 이전 스텝 수정: 상단 점 터치로 이동
- 하단 고정: "다음 →" 버튼 (선택 후 활성화)

## 7. 웹 ↔ 모바일 비교

| 항목 | 반응형 웹 | 모바일 앱 |
|------|---------|---------|
| **주요 사용자** | 보호자, 특수교사, 사회복지사 | 활동지원사, 당사자, 보호자 |
| **정보 밀도** | 고밀도 (테이블, 분할 패널) | 저밀도 (카드, 단일 컬럼) |
| **기록 작성** | 긴 폼, 다중 항목 한 화면 | 스텝 분할, 한 화면 1~2 항목 |
| **파일 첨부** | 드래그&드롭 + 파일 선택 | 카메라/갤러리 네이티브 연동 |
| **타임라인** | 분할 뷰 (목록+상세 동시) | 세로 스크롤 단일 컬럼 |
| **권한 관리** | 전체 매트릭스 테이블 | 카드 목록 + Bottom Sheet |
| **알림** | 헤더 드롭다운 + 알림 페이지 | 푸시 알림 + 탭 배지 + 알림 탭 |
| **오프라인** | 미지원 | 일지 임시저장 (로컬 캐시) |
| **당사자 UI** | 접근성 모드 (대형 폰트) | 전용 간소화 앱 UI |
| **최대 Depth** | D5 (폼 하위 상세) | D4 (스택 3~4 레벨) |
