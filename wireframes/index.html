📥 SVG 임포트 방법

  1. Figma에서 새 파일 생성 후 Page를 "Web"과 "Mobile"로 나눠 분리
  2. SVG 파일을 드래그&드롭 (한 번에 여러 개 가능, 86개 모두 가능)
  3. 각 SVG 그룹을 선택 후 Frame으로 변환 (Ctrl+Alt+G)
  4. 1440×900 (Web) / 390×844 (Mobile, iPhone 14) 프레임에 정렬
