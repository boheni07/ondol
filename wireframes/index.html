📥 SVG 임포트 방법

  1. Figma에서 새 파일 생성 후 Page 1 이름을 "Wireframes"로 변경
  2. 웹 프레임용 Page와 모바일 프레임용 Page를 각각 생성
  3. SVG 파일을 Figma 캔버스에 드래그&드롭 (한 번에 여러 개 가능)
  4. 각 SVG 그룹을 선택 후 Ctrl/Cmd + G로 Frame으로 변환 (Ungroup 후 재그룹)
  5. 또는 Menu → File → Import 로 직접 불러오기

📐 컴포넌트 작업 순서

  1. Primitives 먼저: Button, Input, Badge, Avatar를 컴포넌트로 만들기
  2. 레이아웃 쉘: Sidebar, Header, BottomTabBar를 공통 컴포넌트화
  3. 도메인 컬러: DomainBadge를 variant로 6가지 (medical/education/welfare/daily/transition/legal)
  4. 카드 시스템: RecordCard, PersonCard, NotificationCard
  5. ST-08 전용: IconSelectorCard (당사자 자기표현 전용, 크기 162×140+ mobile)
